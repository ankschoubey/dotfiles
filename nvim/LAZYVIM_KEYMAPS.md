# LazyVim Key Combos

**Leader** = `<space>`

## File Navigation
| Combo | Action |
|-------|--------|
| `<space><space>` | Find files (root dir) |
| `<space>,` | Buffer list |
| `<space>/` | Grep search (root dir) |
| `<space>ff` | Find files (root dir) |
| `<space>fr` | Recent files |
| `<space>fp` | Projects |
| `<space>e` | File explorer |
| `<space>fn` | New file |

## Buffer Management
| Combo | Action |
|-------|--------|
| `[b` / `]b` or `<S-h>` / `<S-l>` | Prev/next buffer |
| `<space>bd` | Delete buffer |
| `<space>bo` | Delete other buffers |
| `<space>bb` | Switch to other buffer |

## Window Management
| Combo | Action |
|-------|--------|
| `<C-h/j/k/l>` | Navigate windows |
| `<C-Up/Down/Left/Right>` | Resize windows |
| `<space>-` | Split below |
| `<space>\|` | Split right |
| `<space>wm` | Toggle zoom |

## Search (Snacks Picker / Telescope)
| Combo | Action |
|-------|--------|
| `<space>sg` | Grep (root dir) |
| `<space>sb` | Buffer lines |
| `<space>sd` | Diagnostics |
| `<space>sh` | Help pages |
| `<space>sk` | Keymaps |
| `<space>s"` | Registers |
| `<space>sm` | Marks |
| `<space>sw` | Search word under cursor |

## LSP
| Combo | Action |
|-------|--------|
| `gd` | Go to definition |
| `gr` | References |
| `gy` | Go to type definition |
| `K` | Hover |
| `<space>ca` | Code action |
| `<space>cr` | Rename |
| `<space>co` | Organize imports |
| `]]` / `[[` | Next/prev reference |

## Git
| Combo | Action |
|-------|--------|
| `<space>gs` | Git status |
| `<space>gd` | Git diff hunks |
| `<space>gb` | Git blame |
| `<space>gl` | Git log |
| `<space>gL` | Git log (cwd) |

## Diagnostics
| Combo | Action |
|-------|--------|
| `]d` / `[d` | Next/prev diagnostic |
| `]e` / `[e` | Next/prev error |
| `]w` / `[w` | Next/prev warning |
| `<space>cd` | Line diagnostics |

## Toggles
| Combo | Action |
|-------|--------|
| `<space>uf` | Toggle auto-format |
| `<space>us` | Toggle spelling |
| `<space>uw` | Toggle wrap |
| `<space>uL` | Toggle relative numbers |
| `<space>ud` | Toggle diagnostics |
| `<space>ub` | Toggle dark background |

## Misc
| Combo | Action |
|-------|--------|
| `<space>qq` | Quit all |
| `<esc>` | Clear search highlight |
| `<C-s>` | Save file |
| `<space>l` | Open Lazy plugin manager |
| `<space>uz` | Toggle zen mode |
| `<space>uC` | Browse colorschemes |
| `<space>n` | Notification history |

## Testing (if neotest extra loaded)
| Combo | Action |
|-------|--------|
| `<space>tt` | Run file |
| `<space>tr` | Run nearest test |
| `<space>tl` | Run last test |
| `<space>ts` | Toggle summary |

## AI (if extra loaded)
| Combo | Action |
|-------|--------|
| `<space>aa` | Toggle AI assistant |
| `<space>ac` | Chat with AI |
